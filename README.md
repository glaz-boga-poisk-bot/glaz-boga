## Какие запросы можно запустить

- **По номеру телефона** — найти связанные имена, email, ники и исторические записи.
- **По email** — увидеть связанные аккаунты, usernames и записи о регистрациях.
- **По username** — проверить связанные профили и историю смены ника, если она есть в базе.
- **По Telegram ID** — проверить связанные записи; телефон может появиться даже при скрытом номере в профиле, если он есть в источниках сервиса.
- **По фотографии** — найти копии снимка и страницы, где он использовался.
- **По ФИО** — собрать подходящие профили и дополнить запрос городом или возрастом.

## Как продолжить поиск

Не останавливайтесь на первом ответе. Если по номеру нашёлся ник, отправьте ник отдельным запросом. Если по нику появился email, проверьте email. Если нашлась фотография, запустите поиск по изображению. Такой порядок помогает постепенно собрать телефоны, почты, usernames, профили, фотографии и другие связанные сведения в одном месте.

### Глаз Бога находит адрес?

В найденной записи может быть адрес, город или регион — в том числе из архивного источника. Проверяйте дату: исторический адрес не обязательно актуален.

### Можно ли найти скрытый номер по Telegram ID?

Да, номер может появиться в результате поиска по Telegram ID или username, даже если он скрыт настройками профиля Telegram. Это происходит, когда связь с номером сохранилась в базе сервиса; наличие такой записи для каждого аккаунта не гарантируется.

### Можно ли найти все регистрации человека?

Можно увидеть регистрации и связи, сохранившиеся в доступных сервису источниках. Полного перечня всех аккаунтов обещать нельзя.
